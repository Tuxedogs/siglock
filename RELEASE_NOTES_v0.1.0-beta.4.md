# SigLock v0.1.0 Beta 4 — Open Beta

This release refines the Settings experience while preserving existing scanner, shortcut, overlay, and updater behavior.

## Improvements

- Settings categories now have distinct, low-contrast section cards.
- Section headers include short descriptions and clearer expand/collapse controls.
- Application version, update checking, and Release Notes remain separate from Settings content.

## Validation

- Existing frontend checks, production build, feature checks, and Rust tests pass.
- The Windows installer builds locally; updater signing remains a CI-only step.
